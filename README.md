# Advanced Database Management

This repository contains academic projects, database designs, SQL implementations, and documentation developed as part of the Advanced Database Management System course.

The repository showcases practical applications of relational database concepts, database modeling, SQL, PL/SQL programming, database operations, and advanced database management techniques.

## Projects

### 1. Midterm Project – CampusXP
**Smart Campus Opportunity, Club Recruitment & Corporate Drive Platform**

A centralized campus recruitment and opportunity management platform connecting students, student clubs, corporate recruiters, and university administrators.

**Key Features:**
- User and Student Profile Management
- Campaign Management and Approval
- Application and Eligibility Management
- Candidate Screening and Evaluation
- Shortlisting and Communication
- Venue and Equipment Management
- Database Auditing and Accountability

**Technologies:** Oracle APEX, SQL, PL/SQL
