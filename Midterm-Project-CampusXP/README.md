# Midterm Project: CampusXP – Smart Campus Opportunity, Club Recruitment & Corporate Drive Platform

CampusXP is a proposed centralized campus opportunity and recruitment management platform designed to connect students, student clubs, corporate recruiters, and university administrators.

The platform aims to simplify internship discovery, corporate recruitment, club applications, candidate evaluation, shortlisting, and campus resource management through a unified system.

The project focuses on relational database design and implementation using Oracle APEX and PL/SQL. It incorporates user and student profile management, campaign approvals, application processing, eligibility validation, screening, evaluations, venue bookings, equipment requests, and database auditing.

Key database concepts and implementations include:
- Relational database design and normalization
- Entity Relationship (ER) diagrams
- SQL queries, joins, and subqueries
- PL/SQL blocks, conditional statements, and loops
- Stored procedures, functions, and packages
- Row-level and statement-level triggers
- Database auditing and access control

**Technology:** Oracle APEX, SQL, PL/SQL

**Project Type:** Academic Midterm Project
